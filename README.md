# بوت تيليجرام — القرآن الكريم كامل

بوت فيه القرآن كامل: **114 سورة، 6236 آية**، نص + صوت، من API مجاني (AlQuran Cloud).

## 1) اعمل البوت وخد التوكن (دقيقتين)
1. افتح تيليجرام وابحث عن **@BotFather**
2. ابعت `/newbot`
3. اختار اسم للبوت (مثلاً: Quran Kareem Bot)
4. اختار يوزر نيم لازم ينتهي بـ `bot` (مثلاً: `quran_kareem_123_bot`)
5. هيبعت لك **توكن** شكله كده: `123456789:ABCdef...` — احتفظ بيه، ده مفتاح البوت.

## 2) شغّل البوت على جهازك
```bash
cd telegram-quran-bot
pip install -r requirements.txt
cp .env.example .env
# افتح ملف .env وحط التوكن مكان النص
python main.py
```
هيطبع `✅ بوت القرآن شغال...` — افتح البوت على تيليجرام وابعت `/start`.

## 3) عشان يفضل شغال 24 ساعة (من غير جهازك)
ارفع المجلد على أي استضافة مجانية، مثلاً:
- **PythonAnywhere** أو **Render** أو **Railway**
- حط متغير البيئة `TELEGRAM_BOT_TOKEN` في إعدادات الاستضافة
- شغّل `python main.py`

## الأوامر داخل البوت
| الأمر | يعمل إيه |
|---|---|
| `/start` | الترحيب والأزرار |
| `/surah 2` | سورة البقرة كاملة |
| `/ayah 2:255` | آية الكرسي |
| `/juz 30` | الجزء الثلاثون كامل |
| `/random` | آية عشوائية |
| `/search الرحمن` | بحث في القرآن |
| `/audio 2:255` | صوت الآية بصوت مشاري العفاسي |

أو اكتب رقم السورة أو اسمها مباشرة في الشات، وهتتبعت لك.

## ملحوظة
- البوت بيجيب النص من الإنترنت (API مجاني)، فمش محتاج تحمّل ملفات قرآن.
- التوكن سري، متشاركوش مع حد.
